## 26 — two-arm sun predicate (`58c9572`)

The defect and its evidence are in the TODO item and the watchdog capture; the
fix is `sunPresent(busMv, currentMa, batteryMv)`:

```c
currentMa >= 1 mA  ||  busMv > batteryMv + 150 mV
```

Every constant is anchored to a measured vector, and the host tests now pin
all four quadrants *from the wire*: night back-feed (0 mA, batt−178 mV →
dark), low light (11.6 mA at batt−90 mV → sun, the row that kills a pure
relative test), charge termination (0 mA at batt+940 mV → sun, the row that
kills a pure current test), strong charge. The go-dark EWMA test now uses the
real night signature (3570 mV vs 3750 mV battery) — an input the old absolute
threshold could never call dark, which is the whole point. Hysteresis band
untouched: the predicate still yields a 0/1 duty-cycle input.

## 25 — verbose schema 2 (34 bytes)

New bytes 22–33: uptime (u32 s), wake-cycle count (u16), `ramCount`/
`uplinkCounter` packed, panel current min/mean/max (0.5 mA/LSB) and bus
min/max (30 mV/LSB), with `DIAG_INFO_PANEL_STATS` (0x80) marking a live
profile. The `PanelStats` accumulator is pure and host-tested (fed with the
measured 2026-07-28 evening decline as its vector); the `.ino` samples the
panel once a minute from the DEV sleep loop via the same wake→CNVR→read→
power-down sequence as the wake-time read, and resets the accumulator after
each verbose TX so every frame carries exactly its own hour.

**Cadence is now genuinely hourly**: `evaluateAndMaybeSendVerbose()` is also
called from inside the DEV sleep loop (millis-gated, so the extra call site is
idempotent), removing the old `max(1 h, wake interval)` thinning exactly where
long winter intervals made status most wanted. All of it — sampler, emission,
stats — is DEV-only by construction: PROD never enters the busy-wait branch
and never sends FPort 3.

Wrap notes, stated rather than discovered later: uptime wraps at 49.7 days,
cycle count saturates at 65535 — both fine for a bench frame PROD never sends.

## 24b — clarity convergence gate (decoder)

Schema-2 frames carry both the EWMA and its age, so the decoder now emits
`clarity` only when `uptime_s >= 86400` (one EWMA time constant); younger
frames report `clarity: null, clarity_converging: true`, with
`expected_daylight_fraction` always alongside. Uptime under-estimates EWMA age
after a warm reset (the EWMA is restored, uptime is not) — the gate errs
toward suppressing, conservative by design.

**Scope honestly stated**: data frames (FPort 11/21) remain ungated. A TTN
formatter is stateless and the 15-byte payload carries no age field, so the
formatter *cannot* gate them; the backend, which has history, is the right
place (folded into item 10's alarm work). The live fixture's `clarity: 0.006`
at f_cnt=0 remains in the tree as the preserved example of the artefact.
