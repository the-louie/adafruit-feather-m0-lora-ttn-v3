**2026-07-28 session — gisebo-05's first full night exposed two defects, both fixed and flashed the same day.** (a) The **DEV sleep loop starved LMIC's clock extender**: `os_runloop_once()` samples the clock only when a job is scheduled, so an idle ~62 min wait let the HAL's `micros()` extender miss a wrap and set `os_getTime()` back 71.6 min — LMIC then deferred each TX past the 2-minute timeout and **~2 of 3 hourly cycles transmitted nothing**, invisibly (`58e4f74`). PROD is immune; deep sleep freezes `micros()`. (b) **`powerSave(true)` was never undone**, so every INA219 reading after a boot's first was the stale register contents — panel V/I frozen at 3.852 V / 15.9 mA across sunset *and* sunrise, the sun EWMA integrating "sun present" in the dark, 192 mAh of fictional harvest (`007a46b`). Both root causes were read from source, not inferred. Also hardened: `LMIC_setTxData2`'s return is now checked, and TX faults **latch** until a diagnostic frame reports them (the old flag could never reach the air — the frame carrying it was dropped by the same failure). Full analysis and the two root-cause walks are in `docs/dev-notes/20260728-*`.

**Items 18–20 come from the follow-up datasheet audit** (`docs/ina219-register-reference.md`, from TI SBOS448G): every register value the firmware can observe is now enumerated, because *both* INA219 defects so far were the same failure mode — a register value nobody had written down. The highest-value finding is that the part's two status flags (**CNVR**, **OVF**) are discarded by the Adafruit accessor, and CNVR would have caught the freeze directly.

**2026-07-27 session — gisebo-05 is LIVE (flashed, joined, on solar).** Shipped and verified on hardware: the error/diagnostics uplink (FPort 1 PROD / 2 DEV) and the **item 16** DEV verbose full-state frame (FPort 3); the status-byte ordering fix; and a real INA219 defect — **a warm reset (RST/watchdog/`NVIC_SystemReset`) leaves the INA219 holding its calibrated config `0x019F`, and the probe (which accepts only the reset value `0x399F`) misdetected it → solar booted PRIMARY**; fixed by soft-resetting the INA219 before the probe read.
